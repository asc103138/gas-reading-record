# 每日報報 ─ 寶可夢讀報探險記錄系統 (Daily News Pokémon Reading Adventure)

![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Google%20Apps%20Script-blue)
![Theme](https://img.shields.io/badge/theme-Pokémon-red)

專為國小「生生用平板」智慧教學情境設計的讀報學習與心得記錄系統。以 Google 試算表作為雲端資料庫，Google Apps Script (GAS) 部署為 Web App，零伺服器維護成本、零資安外洩風險！

---

## 🌟 核心特色

### 1. 👥 小組選篇 ➔ 個人讀報「免手抄一鍵帶入」
- **小組討論選篇室 (`group.html`)**：每組圍坐討論，推派一人在平板登記本日選定的 1~2 篇文章與選擇理由。各組選篇純私密登記，保有獨立思考空間。
- **個人讀報記錄表 (`index.html`)**：同組同學在各自平板選定「所屬組別」，系統自動連線同步今日小隊選篇，**輕輕一點即可將版面名稱與文章標題自動帶入**，免去小學生逐字抄寫與打字錯誤的痛點！

### 2. ⚡ 寶可夢探險主題卡片
- 將讀報心得轉化為收服寶可夢的探險歷程：
  - 🔴 訓練家資料（班級、組別、座號）
  - ⚡ 文章標題與版面
  - 🌿 文章內容說明
  - 💧 重點摘要
  - 🔥 心得感想與學到什麼
  - 🔮 探險疑問與延伸探索
  - ⭐ 冒險星等評價（1~5 星）

### 3. 📱 國小平板觸控優化
- 支援平板本機記憶（自動記住班級代號、組別、座號，下回免重新輸入）。
- 大尺寸觸控按鈕、清晰配色與動畫視覺回饋。

### 4. 🏆 家長成果分享牆 (`parent.html`)
- 即時匯整全班讀報心得，座號與標題清楚並列展示，適合家長會或班級閱讀成果展示。

## 🚀 快速開始與部署

1. **建立 Google 試算表**：
   - 新增一個空白 Google 試算表。
   - 點選上方選單「**擴充功能**」➔「**Apps Script**」。
2. **複製程式碼**：
   - 將 `Code.gs`、`index.html`、`group.html`、`parent.html` 貼入 Apps Script 編輯器對應檔案。
3. **初始化試算表**：
   - 在編輯器執行 `修正試算表()` 函式一次，自動建立標準欄位（「回覆」14 欄、「小組討論」10 欄）。
4. **部署網頁應用程式**：
   - 點選右上角「**部署**」➔「**新增部署作業**」或「**管理部署作業**」。
   - 類型選擇「**網頁應用程式**」，存取權限設為「**所有人 (Anyone)**」。
   - 取得 Web App 網址即可開始使用！

完整圖文詳細步驟請參閱 [部署操作單.md](部署操作單.md)。
